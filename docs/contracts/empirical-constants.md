# Empirical constants and heuristics registry

This document indexes the empirical multipliers, heuristic thresholds, cache bounds, and
upstream spec constants used across CC History Lite. Each value has a single authoritative
owner in code; this index makes every heuristic easy to locate, audit, and recalibrate
when workloads, upstream tools, or measurements change.
